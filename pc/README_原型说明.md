# 平台培训专区 PC 端 HTML 原型 V2

本原型依据《平台培训专区PC端PRD V2》和已经确认的页面框架、专区首页及课程详情视觉样板制作，共27个HTML页面，覆盖PC端MVP001—MVP027。

## 如何进入

直接打开 `index.html`。页面无需安装、登录服务器或连接数据库；所有内容均为静态模拟数据。

## 核心演示流程

### 个人正常流程

专区首页 → 培训课程 → 课程详情 → 个人报名 → 生成平台个人报名编号 → 培训机构受理结果 → 报名订单与支付 → 我的培训 → 在线学习／线下签到 → 培训完成结果 → 培训机构统一送考 → 资格审核结果 → 报名订单与支付 → 考试安排 → 成绩与复核 → 证书与全流程档案。

### 团队正常流程

课程详情 → 团队报名 → 创建团队任务 → 批量导入成员 → 生成H5邀请 → 成员本人确认状态 → 筛选合格成员 → 分批提交报名 → 逐人生成培训报名记录 → 培训机构受理 → 生成团队报名订单 → 在线支付或线下对公汇款。

团队只是报名组织方式。合格成员可以先行形成报名批次，待确认或待补正成员保留在原团队任务中，补齐后再进入下一批次；每个批次分别生成团队报名订单主订单和个人费用明细，不跨批次合并缴费。后续培训、考试和证书仍按个人记录展示。

### 公开查询流程

专区首页或顶部入口 → 证书查验 → 输入证书编号和姓名 → 展示模拟证书状态和允许公开的信息。

## 主要页面

- 公开选择：培训机构列表及详情、课程班次列表及详情、评价项目列表及详情。
- 报名建档：个人报名资料、团队任务列表／编辑／全景详情、报名批次、个人培训报名和报名详情。
- 缴费培训：报名订单、我的培训、在线学习、线下日程签到、培训过程与完成结果。
- 考试取证：培训机构统一送考、资格审核结果、报名订单、考试安排、成绩复核、不合格处置、证书与档案、公开查验。

## 原型模拟说明

- 登录验证码固定为 `123456`。
- 在线支付只模拟支付成功结果，不连接真实支付通道。
- 线下支付演示对公账户、汇款信息和凭证提交；平台核款为模拟结果。
- 上传、下载、筛选、签到、复核和证书查询均为前端交互模拟。
- 页面之间不做真实跨端数据联动，也不建设后端数据库。
- 机构、人员、课程、价格、时间、地址、考试和证书数据均为演示用Mock数据。

## 后续真实开发注意事项

- 智能建造平台必须掌握统一报名入口、人员主档、平台报名编号和跨机构主状态。
- 培训费与考试费分别生成订单；线上和线下款项均由平台统一收款、统一核款。
- 团队成员最终须由本人确认，后续业务必须拆分到个人记录。
- 团队采用受控分批提交：同一成员不得重复进入多个成功批次；每个批次对应一张团队报名订单主订单，支付结果逐人回写。
- 培训完成、资格审核通过、考试费已支付、正式排考、成绩确认和第三方赋码均为硬闸门。
- 资格、成绩和证书结论由评价机构负责，平台只展示和留存，不替代评价机构修改结论。
